# Security Policy

## Supported Versions

The following versions of the project are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0.0 | :x:                |

## Reporting a Vulnerability

Send an email to mail@martinspielmann.de if you want to give me a chance to provide a patch before the vulnerability is disclosed.
I'll try to respond within a day.

Feel free to go for a full disclosure instead and open a GitHub issue with your finding.

As this is a private, spare time project, I will highly appreciate any contribution but won't be able to provide a bounty. 
But (if you like) you will be named in the release notes of the fix and added to the README.
